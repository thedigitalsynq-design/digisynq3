# DigiSynq Cinema Matrix (The Cinema Nervous System - CNS)

> **The Living Theatrical Intelligence, Risk Telemetry, and Asset-Light Operating Protocol for Indian and Global Cinema.**

DigiSynq Cinema unifies the entire theatrical entertainment lifecycle—from asset-light production scheduling to real-time release risk control, live box office tracking, viral cultural amplification, and catalog legacy—into a single, cohesive Studio Operating System.

---

## 🌟 The 5 Synchronized Operational Lenses

### 1. ⚡ Mission Control (Executive Command Deck)
- **Real-Time Studio HUD**: Live Theatrical Risk Score, active titles count, estimated metropolitan circuit occupancy, and synchronized ecosystem nodes.
- **Active Theatrical Slate Spotlight**: Real box office figures, production budgets, and calculated gross return multipliers (e.g. *Manjummel Boys: 12.1x*, *Animal: 9.2x*, *12th Fail: 3.5x*).
- **24-Hour Telemetry Trajectory**: Live dynamic area chart balancing risk mitigation against audience velocity.
- **Live Google News RSS Stream**: Continuous ingestion of trade disclosures, censor updates, and clash alerts.
- **Open-Meteo Circuit Weather**: Live monitoring of meteorological conditions and theater disruption risk across Mumbai, Delhi-NCR, Bengaluru, Hyderabad, and Chennai.

### 2. 🎬 Theatrical Slate Vault (Living Database)
- **Authentic SQLite Engine (`cinema.db`)**: 82+ curated titles with verified cast, directors, runtimes, and synopses.
- **Dual-Metric Film Cards**: Visualizes both the editorial rating (out of 10) AND live operational risk index.
- **360° Film Dossier**: Full overview, financial metrics, editorial pros/cons, and community discussion boards.

### 3. 🛡️ Risk & Crisis Operations (War Room)
- Comprehensive 15-page crisis containment suite.
- Incident registry, spatial theater radar, leak suppression, sentiment polarity tracking, and regional circuit condition matrices.

### 4. 🚀 Cultural Velocity (Social Engine)
- **Live Trend Radar**: Real-time entertainment topics, hashtag spikes, and sentiment velocity.
- **Creator Roster Hub**: Curated network of 200+ verified entertainment catalysts and voices.
- **Theatrical ROI Calculator**: Algorithmic audience conversion and box office uplift projections.
- **Grokbot AI Studio**: Creative meme and narrative engineering suite.

### 5. 🌐 Ecosystem Graph & Suture
- **10 Canonical Node Dossiers**: Complete operational blueprints from Node 01 (Genesis) to Node 10 (Pipeline Activation).
- **Interactive Root Network Canvas**: Clickable stakeholder path tracing across pre-production, stages, and exhibition.
- **Problem Matrix & Scanner**: Diagnosing and resolving industry friction points with asset-light protocols.

---

## ⚡ Global Innovations

- **Live Edge Telemetry Ticker**: Real-time streaming bar displaying Google News RSS headlines, live Forex rates (`USD/INR`, `AED/INR`, `EUR/INR`), and SQLite catalog status.
- **Gemini AI War Room Copilot**: Persistent AI advisor accessible globally via `Ctrl+J` or header trigger, grounded in real database records and current industry telemetry.
- **Universal Command Palette (`Ctrl+K`)**: Universal search indexing all lenses, films, tools, and incidents.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Recharts, Framer Motion
- **Backend**: Express, SQLite (`better-sqlite3`), Session Auth (`bcryptjs`, `express-session`), Google Gemini GenAI SDK
- **Live Telemetry**: Google News RSS parser (`xml2js`), Open-Meteo Weather API, ExchangeRate-API Forex engine

## 🚀 Quick Start (Local Setup)

```bash
# 1. Clone repository
git clone https://github.com/thedigitalsynq-design/digisynq3.git
cd digisynq3

# 2. Install dependencies
npm install

# 3. Start the unified development server
npm run dev
# or: node server.js
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
